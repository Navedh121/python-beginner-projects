# Python Beginner Projects

Where I started. Three small projects I built while learning Python basics and how to work with real APIs. Each one taught me something specific — I moved on to building AI apps and automation agents after finishing these.

---

## Projects

### Weather CLI App
Type in a city name and get the current weather instantly.

**What I learned:** How HTTP GET requests work — sending parameters in a URL, getting back JSON, and pulling out the values you need. This was my first time calling a real API from code.

**Stack:** Python, OpenWeatherMap API

---

### Quote of the Day Bot
Fetches a random quote and prints it in the terminal.

**What I learned:** That API calls are just structured HTTP requests. Once I understood the pattern here — request → JSON response → extract field — I could apply it to any API. This was a stepping stone.

**Stack:** Python, ZenQuotes API

---

### File Organizer Script
Automatically sorts files in a folder into subfolders by file type.

**What I learned:** How to work with the file system using Python's `os` and `shutil` modules. This was my first "automation" — something that saved me real time (my downloads folder was a mess).

**Stack:** Python, os, shutil

---

## Context

These are the foundation. I built them in order, moving from "what is an API" to "okay I can automate things." After finishing these I went on to building AI-powered web apps and autonomous bots.
